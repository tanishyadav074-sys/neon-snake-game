# Neon Snake

A responsive neon-styled Snake arcade game built with React, Vite, JavaScript and CSS.

## Features
- Keyboard controls: Arrow keys or WASD
- Touch swipe controls and on-screen directional buttons
- Easy, Medium and Hard speeds
- Three grid sizes
- Optional obstacles
- Score, high score, games played and best length saved in localStorage
- Pause/resume, reset, game-over state
- Responsive dark neon UI

## Run locally
1. Install Node.js (LTS) from https://nodejs.org/
2. Extract this folder and open it in VS Code.
3. Open a terminal in the project folder.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Deploy
Push this project to a GitHub repository, import it into Vercel, and use:
- Build command: `npm run build`
- Output directory: `dist`
